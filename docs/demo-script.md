# ENTRY demo script (3–4 minutes)

1. Create a sample event with a fixed face price and a 110% resale cap.
2. Show ticket issuance and explain that Bubblegum V2 stores compressed asset state in a Merkle tree.
3. Attempt a 150% resale and show the cap rejection.
4. Attempt a 105% resale and show the intended valid path (only after Bubblegum CPI and payment splitting are integrated).
5. Scan a ticket at the gate, redeem it online, then scan again and show the duplicate rejection.
6. Close with the measurable promise: transparent fees, constrained resale, and verifiable single-use entry.

Do not claim the incomplete CPI or direct-transfer restriction is implemented until its integration tests pass.
